# ASR-XGBoost（最小演示版）

自适应空间正则化 XGBoost（**A**daptive **S**patial **R**egularization **XGBoost）核心思想的**最小可运行演示**，包含**分块自适应 λ 选择**与**多情形模拟研究**。

在标准逐像元 XGBoost 基础上，把**空间连续性**直接嵌入训练目标：用邻域软标签约束每个像元的预测，并用**门控函数**把正则化强度集中到模型最不确定（预测概率接近 0.5）的位置。本仓库进一步展示：

- **生态连通性加权软标签**：用阻力面定义邻域权重，地形屏障两侧的像元不再被当作"邻居"；
- **分块自适应 λ**：在平面上划分"国家"块（可自己圈区域），每块在**块内 k 折交叉验证**上网格搜索最优正则化强度 λ\*，按逐像元 λ 映射训练；
- **多情形模拟研究**：多种数据生成方式 × 多种分块方式 × 多个种子，聚合平均精度（mean±std）。

> 本仓库是公开的"小而真"演示版：合成数据、单文件、秒级运行。完整版（真实数据、CircuitScape 全局连通性成本、FPS 背景采样、真实行政边界、空间分块交叉验证）用于学术论文，暂不公开。

## 数据生成（每环都有标准出处）

| 环节 | 方法 |
|---|---|
| 环境变量场 X1~X3 | **GSTools** Matern 高斯随机场，**嵌套双尺度**（长程趋势 + 局地变异），3 个协变量 |
| 阻力面 R | 地形山脊 + 噪声；**曲折海岸线**（多正弦叠加，阻力=100 绝对屏障） |
| 适宜性 p_true | 协变量响应函数 + **交互项**（非线性空间结构）；碎片块叠加可学习锐边 |
| 观测标签 y | ① 伯努利出现采样 + 分块检测/报告异质性噪声（**漏报的代理**）；② 点过程模式：**LGCP/非齐次泊松**（像元事件数~Poisson(λ(s))，出现=至少 1 事件） |

## 核心方法

训练目标：

$$
\mathcal{L}_{\mathrm{ASR}} = \mathcal{L}_{\mathrm{CE}} + \lambda_i \cdot \delta(\hat p)\,(p - \tilde p)^2
$$

- $p$：模型输出概率；$\tilde p$：软标签（邻域加权均值）
- 门控函数 $\delta(\hat p) = 1 - 2|\hat p - 0.5|$：预测越接近 0.5（越不确定），正则化越强；由基线预测 $\hat p$ 计算并**冻结**（frozen gating），保证逐样本 Hessian 正定
- 软标签 $\tilde p_i = \dfrac{\sum_j w_{ij}\,\hat p_j}{\sum_j w_{ij}}$，连通性加权 $w_{ij} = \exp\!\big(-\beta \cdot (R_i + R_j)/2\big)$
- 分块自适应：$\lambda_i = \lambda^*_{\text{block}(i)}$，每块 $\lambda^*$ 用**块内 k 折 CV** 选择，**1-SE 规则**（取最优 λ 一个标准误内的最小 λ，glmnet 惯例）——平曲线上自动选最小充分正则化，避免随机落点与过平滑；候选范围 0~3.5（λ=0 即无正则化，等价 CE；3.5 为论文敏感性上限）；小区域按**质心最近邻合并**（对应行政分块 strategy B 的"小国合并"，保证块内 CV 稳定）
- 数据划分：总像元按 `--sample`（默认 **40%**）随机采样为数据集（模拟观测稀疏），数据集内按 `--split`（默认 **7:2:1**，与论文口径一致）划分，测试集不参与任何选择

## 运行

```bash
pip install -r requirements.txt

python asr_demo.py                          # 单次详细演示（300×300, 16 块, 40% 采样, 空间 CV 评估与六联图：真值/分块/λ*/CE/ASR/差值）
python asr_demo.py --study                  # 模拟研究：默认全块高噪声 g_noisy2 × 3 分块 × 2 种子 = 6 次（逐模拟缓存）
python asr_demo.py --study --reps 3         # 增加重复种子数
python asr_demo.py --study --gens g_clean,g_noisy,g_barrier,g_lgcp  # 回到 4 生成 × 24 次
python asr_demo.py --study --no-cache       # 忽略缓存，强制全部重跑
python asr_demo.py --blocks regions.npy     # 用自己圈的区域（单次模式）
```

**自己圈区域**（Windows 图形界面）：

```bash
python draw_regions.py
# 左键加点 | 右键闭合一块 | c 撤销 | q 保存退出
python asr_demo.py --blocks regions.npy
```

## 模拟研究（--study）

设计：默认 **g_noisy2（全块高噪声，σ≈0.35）× 3 种分块方式 × 2 个种子 = 6 次模拟**（用 `--gens` 可扩展为 4 生成 × 24 次）。每次模拟同时输出**测试集**指标（AUC / Brier / LogLoss / 平滑度）与 **final 式空间 CV** 指标（3×3 网格块折，块不跨折，每折重训并重算软标签/门控，无泄漏；ASR 默认用**训练侧预选 λ\***（公平版，与测试集同口径）），最后聚合平均（mean±std）并给出 ASR 相对 CE 的平均改善。另输出**子集增益**：仅在 λ\*>0 区域（ASR 实际生效）与 CE∈[0.4,0.6] 风险带（门控最强）的像元池上的 ASR−CE 改善。命名与论文一致：SR(λ=1.0)（固定强度）、ASR（分块自适应）。

- 数据生成：`g_noisy2`（**全块高噪声**，默认）/ `g_hard`（**弱信号困难**：logit 系数 ×0.45，CE 预测大量接近 0.5，放大 ASR 门控收益）/ `g_clean`（低噪声）/ `g_noisy`（高漏报异质性）/ `g_barrier`（强地形屏障）/ `g_lgcp`（点过程 LGCP）
- 分块方式：`p_voronoi`（Voronoi 随机国家块）/ `p_grid`（规则网格块，对应 5°×5° 网格惯例）/ `p_resist`（生态阻力分区）
- 输出：逐次模拟进度（缓存/重跑标记）→ 测试集汇总表 → 空间 CV 汇总表 → 平均改善 → 子集增益 → 配对显著性（每模拟 Δ = ASR−CE，配对 t + Wilcoxon）→ 按 生成×分块 组合表（测试集 + 空间CV）→ λ\* 选择分布
- **缓存**：逐模拟结果存 `study_cache.pkl`（key 含全部参数，改参数自动失效）；二次运行命中缓存秒出；`--no-cache` 强制重跑

示例输出（60 次模拟聚合：g_noisy2 + g_hard × 3 分块 × 10 种子，测试集 + 空间 CV 双口径）：

```

------------------------------------------------------------------
测试集指标（7:2:1 划分，ASR 用训练侧分块 λ*；mean±std）:
指标          CE                        SR(λ=1.0)                 ASR
AUC          0.6683±0.0588      0.6714±0.0579      0.6727±0.0568
Brier        0.2272±0.0160      0.2261±0.0158      0.2259±0.0156
------------------------------------------------------------------

指标          CE                        SR(λ=1.0)                 ASR
AUC          0.6362±0.0517      0.6406±0.0513      0.6414±0.0509

------------------------------------------------------------------
平均改善 (ASR − CE, 空间CV): ΔAUC +0.0052  ΔBrier -0.0018  ΔLogLoss -0.0040

------------------------------------------------------------------
配对显著性（每模拟 Δ = ASR − CE；配对 t + Wilcoxon，n=60）:
  空间CV AUC      Δ+0.0052±0.0033  t=+12.14  p<0.0001  Wilcoxon p<0.0001
  空间CV Brier    Δ-0.0018±0.0009  t=-15.71  p<0.0001  Wilcoxon p<0.0001
  测试集 平滑度    Δ-0.0107±0.0040  t=-20.83  p<0.0001  Wilcoxon p<0.0001
------------------------------------------------------------------
训练侧分块自适应 λ* 选择分布（全部模拟的所有块）:
  λ=0.0: 6 块, λ=0.5: 16 块, λ=1.0: 24 块, λ=1.5: 32 块, λ=2.0: 22 块, ...
```

要点：压力测试场景（全块高噪声 σ≈0.35 + 弱信号）下，ASR 在空间 CV 与测试集上
均显著改善 AUC/Brier/LogLoss（配对检验 p<0.0001），空间平滑度显著降低约 24%；
在门控最强的 CE∈[0.4,0.6] 不确定带增益约为全局 3 倍（验证门控设计）；
λ* 随数据难度自适应（困难场景 95% 的块选 λ>0，干净场景近半数选 λ=0）。

## 与完整版的差异

| 方面 | 本演示（公开） | 完整版（论文，未公开） |
|---|---|---|
| 数据 | GSTools 合成场 + 响应函数 + LGCP | 真实疾病发生数据 + 10 个环境/社会经济协变量 |
| 连通性成本 | 局部阻力近似 $(R_i+R_j)/2$ | CircuitScape 电路理论全局等效电阻（McRae et al., 2008） |
| 分块 | 合成块 / 自圈区域；小区域质心最近邻合并；只做 λ 分块 | 真实行政边界（大国省块 + 小国最近邻合并）；λ 与 β 均分块自适应 |
| 采样 | 随机像元 + 分块检测异质性 | 生态分层 + FPS 最远点背景采样 |
| 验证 | final 式空间 CV（3×3 网格块折，块不跨折，每折重训并重算软标签，无泄漏；ASR 用训练侧预选 λ*，公平版；AUC / Brier / LogLoss，mean±std）+ 测试集评估 + 多情形模拟研究（跨 24 次平均，测试集与空间 CV 双口径） | 空间分块交叉验证（5°×5° 网格块，Roberts 2017 惯例）+ 跨疾病外部验证 |
| 结构 | 单文件演示 | 多模块工程（数据、特征、模型、评估） |
